#### This experiment simulates mass-energy equivalence, demonstrating how a small amount of mass converts into a massive amount of energy. The system calculates the total energy yield using the exact speed of light constant.

### Python
The Python script defines the speed of light as an integer constant and calculates the energy using the E=mc^2 formula. It takes a small mass input in kilograms and returns the energy in joules. The script visually contrasts the initial mass with the immense energy output.

### C
The C implementation uses long double precision to handle the massive numerical values generated by squaring the speed of light. It calculates the energy by multiplying the mass by the constant c squared. The output is formatted to display the scientific notation of the resulting energy.

### Rust
The Rust version handles the large numbers safely using 64-bit floating-point variables. It defines the speed of light as a constant and performs the multiplication to find the energy equivalent. The script prints the energy yield, showing the direct proportionality between mass and energy.

### Shell
The shell script uses awk to perform the E=mc^2 calculation, as bash natively lacks high-precision floating-point math. It passes the speed of light and a sample mass to awk. The resulting energy is formatted and printed, demonstrating how a tiny mass generates an astronomical amount of energy.
