#### This experiment models gravitational time dilation, calculating how time passes slower in a stronger gravitational field. The system computes the time difference between an observer on Earth's surface and one in deep space.

### Python
The Python script uses the gravitational time dilation formula based on Earth's mass, the gravitational constant, and the distance from the center of the planet. It calculates the time dilation factor for a clock on the surface. The script outputs the seconds lost per year due to Earth's gravity.

### C
The C implementation uses math.h to calculate the square root of the gravitational time dilation formula. It defines constants for the gravitational constant, Earth's mass, and Earth's radius. The script accurately computes the fractional time dilation and prints the results.

### Rust
The Rust version implements the mathematical formula using f64 precision for the gravitational constant and planetary mass. It calculates the time dilation factor using the square root method. The output demonstrates the exact relativistic time difference for an observer on the planet's surface.

### Shell
The shell script calculates the gravitational time dilation using awk. It passes the necessary physical constants (G, Mass, Radius, c) to the awk formula. The bash script then formats and outputs the time dilation factor, showing how gravity alters the flow of time.
