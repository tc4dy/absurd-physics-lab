#### This experiment models the embedding geometry of a Morris-Thorne traversable wormhole by calculating the shape function and the embedding profile. The system demonstrates how spacetime is threaded through a throat, connecting two distant regions without a singularity.

### Python
The Python script uses the math module to compute the shape function b(r) = r0^2 / r and the embedding coordinate z(r) via numerical integration. It evaluates the throat condition b(r0) = r0 and prints the embedding profile for increasing radial distances, showing the characteristic flaring-out of the wormhole mouth.

### C
The C implementation uses double-precision arithmetic to calculate the shape function and the embedding profile. It defines the throat radius as a constant and evaluates the condition b(r) < r for all r > r0. The program outputs the embedding geometry, confirming that the wormhole remains traversable without an event horizon.

### Rust
The Rust version calculates the Morris-Thorne shape function using f64 primitives. It enforces the traversability condition at compile-time through explicit bounds checking. The embedding profile is generated by iterating over radial coordinates and printing the resulting z(r) values, reflecting the geometric flare-out of the wormhole.

### Shell
The shell script uses awk to compute the shape function and the embedding profile. It passes the throat radius and a range of radial distances to awk, which evaluates b(r) and z(r) analytically. The bash script then prints the geometry, showing the throat and the asymptotic flatness at large radii.
